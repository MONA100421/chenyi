About me

Hi, I’m Chenyi Weng, a MERN Full-Stack Developer with a strong foundation in building production-style web applications from the frontend UI layer to secure, scalable backend APIs. I’m currently pursuing my M.S. in Spatial Data Science at the University of Southern California (STEM), and I am actively seeking Software Engineer / MERN Full-Stack Developer roles.

My background combines software engineering, system design, and data-driven thinking. I started with a BBA in International Business and Information Management, where I built a solid understanding of systems, data structures, and application architecture. Over time, I transitioned fully into engineering-focused roles, with hands-on experience designing, implementing, and shipping full-stack applications.

I am currently building a production-style MERN full-stack e-commerce platform using React, TypeScript, Node.js, Express, MongoDB, and JWT-based authentication. The project is designed to mirror real-world B2C platforms and focuses on clean architecture, security, maintainability, and user experience rather than simple CRUD demos.

On the frontend, I implemented a modular React architecture with reusable components, custom hooks, and centralized state management using Redux Toolkit. The application supports authentication-aware UI rendering, role-based access control (admin vs. user), protected routes, pagination, search, cart state synchronization, and responsive design across devices.

On the backend, I designed RESTful APIs using a layered architecture (controllers, services, models, middlewares) to ensure scalability and separation of concerns. I modeled core e-commerce domains including User, Product, and Cart, implemented request validation and authentication middleware, and built secure cart and product workflows with JWT-based auth and permission checks.

Beyond feature implementation, I focus on engineering fundamentals such as API design, error handling, data validation, state consistency, and maintainable code structure. I’m comfortable working across the stack, debugging end-to-end issues, and thinking about how real users and admins interact with systems at scale.

I’m particularly interested in roles where I can work on full-stack web applications, scalable backend services, and user-facing products. I enjoy building systems that are reliable, secure, and thoughtfully designed, and I’m eager to grow within a strong engineering team as a Full-Stack or Software Engineer.

If you’re looking for a developer who understands both frontend product thinking and backend system design—and who has hands-on experience building real MERN applications— I’d love to connect.
